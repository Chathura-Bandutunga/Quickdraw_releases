# Keyboard reference

Written for macOS. On Windows, `⌘` is `Ctrl`, `⌥` is `Alt` and `⌃` is `Ctrl`.

## Files

| | |
|---|---|
| `⌘N` | New diagram |
| `⇧⌘N` | New symbol… |
| `⌘O` | Open… |
| `⌘S` | Save |
| `⇧⌘S` | Save As… |
| `⌘E` | Export… |
| `⌘Q` | Quit |

*File ▸ Export patch list (CSV)…* and *File ▸ Add symbols from this diagram…* have no
shortcut.

## Editing

| | |
|---|---|
| `⌘Z` / `⇧⌘Z` | Undo / Redo |
| `⌘C` / `⌘V` | Copy / Paste |
| `⌘D` | Duplicate |
| `⌘K` | Quick Add — type a name, press Return |
| `⌘G` | Insert container |
| `R` | Rotate the selection 90° |
| `Backspace` or `Delete` | Delete the selection |
| Arrow keys | Nudge by one grid step |
| `Esc` | Cancel an armed symbol or a wire drag |

`R` and `Backspace` deliberately have no menu-level shortcut, so they keep working as
ordinary typing when you are in a text field.

## Arranging

| | |
|---|---|
| `⌃⌥←` | Align left |
| `⌃⌥→` | Align right |
| `⌃⌥↑` | Align top |
| `⌃⌥↓` | Align bottom |

Distribute horizontally and vertically are on the *Edit ▸ Arrange* menu, without
shortcuts.

## View

| | |
|---|---|
| `⌘+` / `⌘-` | Zoom in / out |
| `⌘0` | Zoom to fit |
| `⌘'` | Show grid |
| `⇧⌘'` | Clean View — hide everything that is not the diagram |

## Mouse

| | |
|---|---|
| Drag a tile onto the canvas | Place a symbol |
| Click a tile, then click the canvas | Place a symbol |
| Drag from a port to a port | Wire them together |
| Drag from a port into empty space | Place *and* wire a new symbol, in one step |
| Drag on empty canvas | Rubber-band select |
| Right-click a symbol or container | Properties card at the cursor |
| Right-click a wire | Waypoints, connections, properties, delete |
| Right-click a component tile | Favourites; edit and delete, for your own symbols |
| Drag a label | Move it |
